# Оптимизация карточки Google Play

Выбери режим по задаче; не запускай полный ASO-процесс для одной проверки.

## Метаданные

Прочитай [контракт](references/knowledge/play-metadata.md), затем проверь готовый JSON:

```bash
python3 <путь-скилла>/references/shared/cli.py validate metadata/listings.json
```

Ошибки структуры/длины блокируют загрузку. `audit.warnings` — подсказки редактору; они не являются автоматическим решением о соответствии policy. Инструмент считает Unicode code points, поддержка локали и отображение окончательно проверяются Console. У Google нет опубликованного «ASO-скора» этого набора: не выдавай полноту карточки или длину текста за прогноз позиций.

## Отзывы

Принимай нормализованный CSV `review_id,rating,text`. Убери дубли по ID и отдели отзывы выбранной версии/страны/периода до анализа. Не распространяй результат выборки на все отзывы магазина.

```bash
python3 <путь-скилла>/references/shared/cli.py reviews research/reviews.csv --output reports/reviews.json
```

Словарь тем работает для EN/RU, метки могут пересекаться и ошибаться. Прочитай примеры низких оценок, выдели повторяющиеся проблемы, отличи баги/подписку/UX от пожеланий. Итог содержит объем выборки, ограничения языка, подтверждающие выдержки и рекомендации продукту/карточке. Ответы пользователям публикуются только если это входит в поручение.

## Эксперимент

Прочитай [метрики](references/knowledge/play-metrics.md) и заполни [шаблон](references/docs/experiment-template.md). Выбери поддерживаемый элемент, одну гипотезу, текущий control, primary metric и защитные метрики. Не обещай универсальный объем выборки, срок или значимость; используй настройки эксперимента и пригодность данных Console. Сохрани исходный материал и итоговое решение. Не объявляй победителем вариант после произвольного раннего просмотра.
