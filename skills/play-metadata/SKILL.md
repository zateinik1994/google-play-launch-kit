# Google Play metadata

Подготовь метаданные выбранного приложения и его локалей в формате `Listing`: объект с языковыми тегами и полями `title`, `shortDescription`, `fullDescription`, необязательным `video`. Прочитай [ограничения и рекомендации](references/knowledge/play-metadata.md); сохраняй факты о продукте, тон и целевые языки пользователя.

У Google Play нет отдельного App Store keyword field: поисковые фразы должны естественно входить в видимые пользователю тексты. Не переноси iOS-лимиты и поля в Android-файл. Не выдумывай функции приложения и доказательства эффективности.

Для детерминированной проверки используй bundled CLI из [references/shared/play_api.py](references/shared/play_api.py):

```bash
python3 <skill-directory>/references/shared/play_api.py validate --input listings.json
python3 <skill-directory>/references/shared/play_api.py plan --input listings.json --current before.json
```

`<skill-directory>` замени абсолютным путем к этому скиллу. Без baseline можно опустить `--current`; такой план не знает текущего состояния магазина. По умолчанию `apply` также выполняется offline без изменения Google Play.

Если запрос касается connected карточки или API-публикации, прочитай [инструкцию API](references/docs/play-api.md), подготовь проверенный файл и понятное сравнение значений. Используй уже данное пользователем разрешение на конкретное изменение; подготовка текстов сама по себе не дает разрешение на commit. Live CLI требует явного `--live` и сохраняет свежий снимок перед изменением. Не запускай live для демонстрации, не повторяй commit с неизвестным исходом.

Учитывай, что `list` и `export` создают временный edit и делают невалидным предыдущий edit той же учетной записи. Согласуй работу с уже активным инструментом публикации, если он присутствует в контексте. Не отменяй чужой review: bundled CLI задает `ERROR_IF_IN_REVIEW`.

Верни локальный файл или обновленную карточку согласно запросу, кратко укажи локали и результат проверки. Отличай локальную проверку лимитов, серверный validate, commit и фактическое появление изменений в магазине. Скриншоты, AAB, релизы, Data safety, custom store listings и запуск Google Ads не поддерживаются этим CLI.
